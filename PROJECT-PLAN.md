# Project plan: MAISON / 08

## Brief

**Type:** Website design

**Problem:** A small product shop needs an inviting path from discovery to a confident product choice.

**Audience:** A design-conscious shopper comparing one considered home object.

## Experience flow

1. Arrive at a direct, descriptive introduction.
2. Review the sample interface and its scope before interacting.
3. Try the core control: Choose a product finish and update a demo basket.
4. See a local result or demonstration state without sending a request to a service.

## Interaction

Choose a product finish and add it to a local demo basket; no purchase is sent.

## Key design decision

Treat material, scale and product details as part of the product story instead of decorating a generic catalog.

## Boundaries

Sample product, price and inventory are fictional; basket state is demonstration-only.

All named businesses, people, products, schedules, prices and quantitative values are fictional portfolio content. Replace them only with verified, permissioned material.

## Next iteration

Connect real inventory and a compliant checkout only after product, shipping and returns information are available.

## Learning goals

- Structure a complete page with meaningful headings, landmarks and labelled controls.
- Separate visual rules in CSS from interaction logic in JavaScript.
- Make states understandable with keyboard controls and live status text.
- Document assumptions and the boundary between a helpful prototype and a production service.
